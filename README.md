Browser-based interactive teaching tools for AP Physics C (Mechanics + E&M).

Self-contained single-file HTML — no build step, no dependencies. Open in any browser or deploy via GitHub Pages.

## Design

- **Aesthetic**: Warm cream parchment / physics textbook page
- **Fonts**: Fraunces (display) · Manrope (body) · JetBrains Mono (numerics) · Noto Sans/Serif TC
- **Bilingual**: English AP terminology + Traditional Chinese intuitive explanation
- **Target**: Samsung Tab S9 Ultra landscape split-screen / any desktop browser

## Usage

Each HTML is a standalone artifact. Open locally or via GitHub Pages URL.
During class: screen-share the browser tab in Zoom/Google Meet.
After class: share the Pages URL with students for self-review.
